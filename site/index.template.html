Get started

Install in a minute.

Install a userscript manager, open an install link, and confirm the install. Updates are served from GitHub Pages; no manual copying is required.

Tampermonkey Violentmonkey
  1. 01Install Tampermonkey or Violentmonkey.
  2. 02Choose a script above and press Install.
  3. 03Reload GeoGuessr and open the Userscripts settings tab.

One place to configure

Native settings, shared tab.

Open GeoGuessr settings

Every installed script registers a sub-tab in the official in-game settings dialog.

No floating overlays

Configuration stays inside GeoGuessr's own settings UI, with native toggles, ranges, and buttons where possible.

Stored locally

Configuration is versioned and stored in the browser. No account or external service is required.
