Setup

Installation

Install a userscript manager, open an install link, and confirm the installation. Updates are served from GitHub Pages.

Tampermonkey Violentmonkey

Install status is detected locally after the current script version has run on this page at least once. Existing installs may need one manual update first.

  1. 01Install Tampermonkey or Violentmonkey.
  2. 02Choose a script above and press Install.
  3. 03Reload GeoGuessr and open the Userscripts settings tab.

Configuration

Settings

Official settings dialog

Each installed script registers a sub-tab in GeoGuessr's in-game settings dialog.

No floating overlays

Configuration stays inside GeoGuessr's own settings UI, using native controls where possible.

Stored locally

Settings are versioned and stored in the browser. No account or external service is required.

Migration

Legacy gist scripts show a permanent notice. Install the current versions here and remove the old scripts from your userscript manager.
